# Contributing to Periodic Table Dataset

Thank you for your interest in improving this dataset!

## How to Contribute
1. **Reporting Errors:** If you find incorrect data for any element, please open an issue with the correct value and a reliable source (IUPAC, NIST, etc.).
2. **Missing Fields:** If you have suggestions for new properties to include, open an issue for discussion.
3. **Machine Learning Experiments:** If you've used this dataset to train a model, feel free to share your results!

## Submission Process
1. Fork the repository.
2. Create a new branch.
3. Commit your changes with descriptive messages.
4. Open a Pull Request.
